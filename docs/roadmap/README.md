# Deferred work: Blueprint Genie

This folder records requested capabilities that are not complete production features. Each placeholder defines a scope boundary and a starting point for future planning. A placeholder is not a design approval, integration, product commitment, or evidence that the capability exists.

## Deferred areas

| Placeholder | Current boundary |
| --- | --- |
| [Multi-user VR](./multi-user-vr.md) | The headset experience is single-device; guests cannot join or speak in a shared room. |
| [AI collaborator](./ai-collaborator.md) | The local prototype has no connected LLM and cannot supply professional advice. |
| [Design editor](./design-editor.md) | The editor and renderings are illustrative; geometry, editor behavior, and exports need validation. |
| [Jurisdiction research](./jurisdiction-research.md) | County outlines and human-recorded research do not establish site-specific authority or compliance. |
| [Professional network](./professional-network.md) | Specialist categories are suggestions only; there is no vendor directory, verification, or placement network. |
| [Release validation](./release-validation.md) | The release gate and latest verified results are tracked separately. |

## Priorities before expanding the product

1. Resolve current type and test failures; establish a passing build and regression baseline.
2. Keep the construction-safety boundary independent of any model, estimate, checkbox, or headset interface.
3. Define data minimization, consent, access control, and retention before introducing shared sessions or external AI.
4. Have qualified design, accessibility, life-safety, legal, and worker-safety professionals review product claims and workflows before representing them as authoritative.
5. Add browser, keyboard, screen-reader, mobile, and supported-headset acceptance tests for every implemented capability.

## Working rules

- Do not describe placeholder or planned behavior as working.
- Do not collect exact site, parcel, or security-sensitive details for these prototypes.
- No generated output may be labeled a blueprint, engineered design, approved plan, code-compliant solution, vendor quote, or worker-safety plan.
- Missing site information, qualified review, source evidence, or worker-safety controls must remain visible. They cannot be bypassed by a collaborator, exported file, or user acknowledgement.
